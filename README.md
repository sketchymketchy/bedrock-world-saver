# Bedrock World Rescue Tool

A Node.js utility to intercept and dump local Minecraft Bedrock terrain chunks over LAN when traditional file transfers or direct joins fail.

## Prerequisites
* [Node.js](https://nodejs.org/) (v18 or higher)
* Minecraft Bedrock Edition on PC
* Target host device (Phone/Tablet) on the same Wi-Fi network
